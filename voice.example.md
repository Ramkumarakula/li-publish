## Post structure (every post, in this order)

1. **Hook:** one line saying what I built, in plain words. No clickbait, no curiosity gaps, no emoji in this line.
2. **Why I built it:** the real problem or frustration that made me start.
3. **What it does:** 2-4 short lines, main features only.
4. **Who it's for:** the specific people who would use it.
5. **Value:** what it saves or improves for them (time, cost, effort, learning). Use only numbers given in the input. If none are given, describe the benefit without a number. Never invent metrics, and never insert `{{your number}}` placeholders for this section; describe the benefit in words instead.
6. **Stack:** one line, the main tools.
7. **GitHub link:** only if the input provides one. Never guess or construct a URL. If there is none, leave this section out entirely.
8. **Close:** one question or a one-line ask (feedback, ideas, try it). Not both.

Blank line between every section.
